Client Integration

Configuration instructions for popular content filters and DNS daemons.

Add as an external subscription in the uBlock Origin dashboard:

# 1. Open uBlock Origin Dashboard -> "Filter lists" tab
# 2. Scroll to the bottom and expand "Custom"
# 3. Check "Import..." and paste the URL below:
https://hosts.domi.my.id/AIO_Filter_List.txt

# 4. Click "Apply changes" in the top bar to pull rules

Configure in the AdGuard Home Web Administrator interface:

# 1. Navigate to: Filters -> DNS blocklists
# 2. Click "Add blocklist" -> "Add a custom list"
# 3. Name: "AIO Filter List"
# 4. URL:
https://hosts.domi.my.id/AIO_Filter_List.txt

# 5. Click Save. The daemon will parse and compile rules automatically.

Add to Pi-hole v5 / v6 adlists database:

# In Pi-hole Web Admin:
# 1. Go to: Adlists (Group Management -> Adlists)
# 2. Add Address:
https://hosts.domi.my.id/AIO_Filter_List.txt
# 3. Click "Add"

# Then update gravity via terminal or web interface:
pihole -g

Automated fetch with conditional HTTP cache validation:

# Download using curl with atomic temporary file swap
curl -sSL --fail --compressed \
  "https://hosts.domi.my.id/AIO_Filter_List.txt" \
  -o AIO_Filter_List.txt.tmp && mv AIO_Filter_List.txt.tmp AIO_Filter_List.txt

# Verify rule count
wc -l AIO_Filter_List.txt

Pipeline Architecture

Deterministic aggregation lifecycle executed daily via GitHub Actions.

+---------------------------------------------------------------------------------------------+ | AIO-FilterList Pipeline | +---------------------------------------------------------------------------------------------+ | | | [18 Upstream Sources] (AdGuard, EasyList, OISD, HaGeZi, Fanboy, 1Hosts, URLhaus, etc.) | | | | | v | | [Stage 1: Fetch] ----> curl parallel download to filters/.<file>.tmp | | HTTP 200 & non-empty size verification before atomic move | | | | | v | | [Stage 2: Merge] ----> single-pass awk stream (CRLF strip, discard comments ^[!#]) | | piped directly into LC_ALL=C sort -u (deduplication) | | | | | v | | [Stage 3: Artifact] -> prepend official Adblock header with dynamic timestamp & counts | | atomic swap into AIO_Filter_List.txt (34 MB, 1.03M+ rules) | | | | | v | | [Stage 4: Telemetry] awk HTML comment marker injection into README.md | | write metadata telemetry to build.log | | | | | v | | [Stage 5: Edge Deploy] published to GitHub Pages (hosts.domi.my.id) & CDN mirrors | | | +---------------------------------------------------------------------------------------------+
