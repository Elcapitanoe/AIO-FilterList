Pipeline Architecture

Deterministic 4-stage pipeline built entirely on POSIX shell and coreutils.

STAGE 01
Staged Parallel Fetch
Downloads 18 upstream lists into isolation buffers (.tmp). Validates HTTP 200 and non-empty payload before atomic swap. Swallows no child exit codes.
STAGE 02
Streaming Deduplication
Single-pass awk strips comment headers and carriage returns, piping directly into LC_ALL=C sort -u. Processes 1.2M+ rules in <3s.
STAGE 03
Telemetry & Marker Injection
Parses build metrics and injects updated routing tables directly into protected HTML comment blocks without clobbering documentation.
STAGE 04
Anycast CDN Delivery
Artefacts deployed to hosts.domi.my.id edge GitHub Pages and globally mirrored across jsDelivr and secondary reverse proxies.

Client Setup Guide

How to configure AIO Filter List in your preferred client.

  1. Open uBlock Origin Dashboard (gear icon).
  2. Navigate to the Filter lists tab.
  3. Scroll to the bottom and expand Import....
  4. Paste https://hosts.domi.my.id/AIO_Filter_List.txt into the text box.
  5. Click Apply changes at the top.
  1. Navigate to your AdGuard Home Dashboard.
  2. Go to Filters → DNS blocklists.
  3. Click Add blocklist → Add a custom list.
  4. Name the list: AIO-FilterList.
  5. Paste URL: https://hosts.domi.my.id/AIO_Filter_List.txt.
  6. Click Save and wait for the download and compile step to complete.
  1. Open Pi-hole Admin Console.
  2. Go to Group Management → Adlists.
  3. Paste https://hosts.domi.my.id/AIO_Filter_List.txt in the Address field.
  4. Add a comment (e.g., AIO Aggregated Mirror) and click Add.
  5. Run Gravity update under Tools → Update Gravity.
  1. Open Brave and type brave://settings/shields/filters in the address bar.
  2. Scroll to the bottom to Custom Filters.
  3. Click Add custom filter list.
  4. Paste https://hosts.domi.my.id/AIO_Filter_List.txt.
  5. Click Submit and verify the filter updates.
